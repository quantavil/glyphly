**GLYPHLY** is a high-craft, precision Unicode typography studio and aesthetic specimen laboratory. It transforms plain text into **180+ authentic mathematical, calligraphic, and cipher styles** across 13 curated taxonomies—with live typographic telemetry, an architectural scale ruler, quick case transformations, instant clipboard copying, and zero visual slop.

---

## Highlights

- ✦ **180+ Authentic Typographic Styles**: Comprehensive math alphabets, blackletter Fraktur, cursive scripts, geometric boxed tiles, ancient runes, ciphers, combining diacritics, and glitch styles.
- ✦ **Guaranteed Depth Per Taxonomy**: Every single category contains **at least 8 distinct, authentic styles** (no sparse or 1-style categories).
- ✦ **Rich Default Starred Collection**: Boots with **9 curated favorites** representing diverse typographic genres (Bold, Blackboard Double-Struck, Fraktur, Circled Spheres, Cyberpunk Shades, Tibetan Wings, Small Caps, Zalgo Glitch, SGA Galactic Script).
- ✦ **Architectural Precision Scale Ruler**: Interactive drafting ruler with live needle position indicator, percentage readout, and bidirectional drag-and-scroll navigation.
- ✦ **Live Typographic Telemetry**: Real-time evaluation of visual graphemes, UTF-16 code units, UTF-8 byte payload, word count, line count, characters-per-line (CPL), and readability metrics.
- ✦ **Zero False Positives**: Intelligent grapheme support detection that accurately handles symmetric inverted letters, phonetic glyphs, combining mark overlays, and lookup ciphers.
- ✦ **Tactile Studio Controls**: Quick case conversion pills (`UPPER`, `lower`, `Title`, `⇄ Flip`), live font-size slider (`14px–48px`), and theme switching (`Dark` / `Light`).
- ✦ **Responsive Editorial Layout**: Dual-panel studio workstation on desktop with collapsible, gesture-friendly controls on mobile devices.
- ✦ **Bespoke High-DPI Vector Favicon**: Crisp squircle monogram with double-struck detailing and golden sparkle accent (`✦`), legible from 16px tab icons to 512px app displays.

## Technical Stack & Architecture

- **Runtime & Package Manager**: [Bun](https://bun.sh) (v1.4+)

- **Language**: [TypeScript](https://www.typescriptlang.org) (v7) in strict mode
- **Bundler & Dev Server**: [Vite](https://vitejs.dev) (v8)
- **Linter & Formatter**: [Biome](https://biomejs.dev) (v2)
- **Test Suite**: [Vitest](https://vitest.dev) & Bun Test (188+ tests validating grapheme integrity, coverage, and category invariants)

## Getting Started

### Prerequisites

Ensure you have [Bun](https://bun.sh) installed (`>= 1.4.0`):

```bash
curl -fsSL https://bun.sh/install | bash
```

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/quantavil/glyphly.git
cd glyphly
bun install
```

### Development Server

Start the local Vite dev server with instant hot module replacement:

```bash
bun run dev
```

Visit `http://localhost:5173/` in your browser.

### Running Tests

Execute the comprehensive test suite across all 180+ styles and category constraints:

```bash
bun test
```

Or run Vitest in watch mode:

```bash
bun run test:vitest
```

### Code Quality & Linting

```bash
# Check code formatting and linting rules
bun run lint

# Automatically format code using Biome
bun run format
```

### Production Build

Typecheck and generate optimized production static assets in `dist/`:

```bash
bun run build
```
